# Va.Si.Li-Lab
a **V**R-L**a**b for **Si**mulation-based **L**earn**i**ng

# Abstract
Va.Si.Li-Lab was established as part of the project "Digital Teaching and Learning Lab" (DigiTeLL) at the Goethe University Frankfurt. 
It has since evolved into a highly capable and flexible VR framework for enabling simultaneous, multi-user engagements.

# Projects
| Project | Va.Si.Li-Lab is used for |
|---|---|
| [DigiTeLL](https://texttechnologylab.github.io/Va.Si.Li-Lab/projects/digitell/) (Goethe University Frankfurt) | Origin of Va.Si.Li-Lab: simulation-based learning in VR for teaching |
| [ViCom / GeMDiS](https://texttechnologylab.github.io/Va.Si.Li-Lab/projects/vicom/) (DFG SPP 2392) | Gestures in dialogue: VR-based multimodal data collection |
| [New Data Spaces / FACES](https://texttechnologylab.github.io/Va.Si.Li-Lab/projects/faces/) (DFG SPP 2431) | Survey interviews in VR with [InterView](https://texttechnologylab.github.io/InterView/), see the [FACES studies](https://texttechnologylab.github.io/FACES/studies/) |

# Systems using Va.Si.Li-Lab
* [InterView](https://texttechnologylab.github.io/InterView/): VR survey interviews, with the interviewer in a web browser ([paper](https://doi.org/10.2139/ssrn.7459949))
* ReEmote: emotion representation for avatars and their environment ([paper](https://texttechnologylab.github.io/Va.Si.Li-Lab/publications/#reemote), XR Salento 2026, accepted)
* Va.Si.Li-ES: event system for environment changes, voting and feedback, `Assets/Lab/EventSystem` ([paper](https://doi.org/10.1145/3648188.3675154))
* VR-ParlExplorer: plenary debates in VR with chatbot members of parliament ([paper](https://doi.org/10.1145/3720553.3746672))
* News in Time and Space: global news events as geospatial hypertext on a virtual globe ([paper](https://doi.org/10.1080/13614568.2024.2383601))
* Viki LibraRy: a collaborative VR library for browsing hypertext ([paper](https://doi.org/10.1080/13614568.2024.2383581))
* Semantic Scene Builder: text-to-3D scene generation, edited in VR ([paper](https://doi.org/10.1007/978-3-031-35748-0_32))
* FraGA: the Frankfurt VR Gesture–Speech Alignment corpus ([paper](http://semdial.org/anthology/Z25-Luecking_semdial_3316.pdf))

Details: [Systems](https://texttechnologylab.github.io/Va.Si.Li-Lab/systems/) · [Publications](https://texttechnologylab.github.io/Va.Si.Li-Lab/publications/)
