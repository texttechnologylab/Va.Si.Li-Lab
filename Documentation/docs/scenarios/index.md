# Scenarios

A scenario is a scene plus its [scene definition](../getting_started/adding_scenes.md) (roles, levels, spawn points).
Scenario scenes made for studies are kept in the projects that run them; the public repository contains the
[sample scenes](../getting_started/special_scenes.md):

| Scene | Purpose |
|---|---|
| `Example` | Minimal scenario to start a new scene from |
| `InterViewStart`, `InterView`, `InterViewReturn` | [InterView](../systems.md#interview): token entry, the interview room (seat, mirror, in-world browser, WebRTC connection to the interviewer) and the end screen |
| `Tutorial` | Learn the controls |
