# Va.Si.Li-Lab

![Va.Si.Li-Lab](images/logo/vasili-lab.svg){ width="420" }

## Description
a **V**R-L**a**b for **Si**mulation-based **L**earn**i**ng.

Va.Si.Li-Lab is a Unity framework for collaborative, multi-user VR with customisable avatars and environments.
It was established in [DigiTeLL](projects/digitell.md) and is used in several [projects](projects/index.md).
Systems built on it, such as [InterView](systems.md#interview) for VR survey interviews, are listed under
[Systems](systems.md).



## Disclaimer
This documentation is work in progress.

And not all functions described here are implemented yet.
