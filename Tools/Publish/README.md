# Publish tools

Scripts for publishing this dev repo to the public repo
([texttechnologylab/Va.Si.Li-Lab](https://github.com/texttechnologylab/Va.Si.Li-Lab)).
Run them from the repo root in Git Bash. Plan and background: `Documentation/PublicMigration.md`.

> Generated by Claude (Anthropic's AI assistant, via Claude Code) in October 2026.

| Script | What it does |
|---|---|
| `check-public.sh` | Checks `Assets/Lab` for references to private/Asset Store content, hard-coded hosts, secrets and the keystore setting. Exit code 1 = blocking issue. |
| `preview-public.sh <dir> [public-repo]` | Copies what would be published from the working tree into `<dir>` so you can open it in Unity. No commit needed. |
| `export-public.sh <branch> <public-repo>` | Rewrites the committed history of `<branch>` down to the public files and merges it into a new `sync/dev-<date>` branch of the public repo. Never pushes. Needs [uv](https://docs.astral.sh/uv/) (runs `git-filter-repo`). |

| File | Used by | Contents |
|---|---|---|
| `public-paths.txt` | export, preview | Paths that are published |
| `public-exclude.txt` | export, preview | Paths that are never published, even in old commits |
| `public-replace.txt` | export | Text scrubbed from every commit (credentials, keystore path, Meta app ID) |

Typical run: `check-public.sh` → `preview-public.sh` → commit → `export-public.sh` → review the branch → PR on GitHub.
